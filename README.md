# Clean Desktop

A small, fast desktop app written in Rust for tidying up your desktop. It walks you through every file and folder one at a time, shows a preview and the details that matter, and lets you decide — **keep** or **delete** — with the mouse or the keyboard.

> [!NOTE]
> **This application was made completely with AI.** All of its code, design and documentation were generated by an AI assistant (Claude by Anthropic) from a short natural-language description. It has been tried out but not reviewed line by line by a human. Use it at your own discretion — deleted items go to the Recycle Bin, so nothing is removed permanently.

## Features

- **Previews** for images, text and code files, folders (total size, file and folder counts, breakdown by type, contents), Windows shortcuts (`.lnk`, including whether the target still exists) and web links (`.url`)
- **Details** at a glance: size, type, modified / created / last accessed (relative and exact), location
- **Hints** that help you decide quickly: broken shortcuts, empty files and folders, names that look like copies (`- Copy`, `(2)`), installers, archives that seem to be extracted already, items untouched for over a year, very large items
- **Safe by design**: decisions are only staged; a summary screen shows everything marked for deletion before anything happens, and items are moved to the **Recycle Bin**
- **Undo** any decision, sort by age, name, type or size
- Previews load in the background, so the UI stays responsive
- Dark, minimal look

## Keyboard shortcuts

| Key | Action |
|---|---|
| `K` / `→` | Keep |
| `D` / `←` / `Del` | Mark for deletion |
| `↑` / `↓` | Previous / next item |
| `Enter` | Open with the default app |
| `E` | Show in Explorer |
| `Ctrl+Z` / `Backspace` | Undo |
| `F` | Finish and review |
| `Ctrl+Enter` | Move marked items to the Recycle Bin (on the summary screen) |
| `F5` | Scan again |

## Getting started

Requires a recent [Rust toolchain](https://rustup.rs/).

```bash
git clone https://github.com/Dornkimik/clean-desktop.git
cd clean-desktop
cargo run --release
```

By default it cleans your desktop. To clean another folder, pass its path:

```bash
cargo run --release -- "D:\Downloads"
```

Built and tested on Windows 11. Hidden and system files (such as `desktop.ini`) are skipped.
